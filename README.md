# 邓云个人网站

以 Python 标准库作为本地服务器的响应式个人品牌网站，无需安装第三方依赖。

## 本地运行

```bash
python3 app.py
```

浏览器打开 <http://127.0.0.1:8000>。

也可指定监听地址和端口：

```bash
python3 app.py --host 0.0.0.0 --port 8080
```

## 上线前需要替换

- 首页肖像占位区：替换为本人授权专业照片
- 联系区：补充公开邮箱、微信与视频号二维码
- 项目卡片：补充真实课程、产品界面与作品图片
- 出版信息：核准封面、作者、出版社、年份和 ISBN
- 表单：接入邮件服务或实际后端接口

所有页面文案均依据提供的《邓云个人网站知识库（2026-08-28）》整理。
